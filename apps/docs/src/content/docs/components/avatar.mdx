`.aparte-avatar` stands for a person: their picture (`.aparte-avatar__image`), or their
initials when there is none. It is the same object as a message's avatar, so a size set here
resizes the chat's avatars too. `--xs` to `--xl` size it, `--circle` and `--square` shape it, and
`.aparte-avatar-group` overlaps several, with a `+3` for the rest.

The corner, the initials and the overlap are fractions of the size, so they stay in proportion
whatever size you pick.

## Accessibility

- A picture needs an `alt` that names the person; initials alone may need an `aria-label` with
  the full name.
- In a group, the `+3` should say what it counts ("3 more people").
