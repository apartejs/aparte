The figures a reporting tool returns, written in the chat's language: sums in their currency,
percentages, compact counts, durations. A change says which way it went; `good` says which way is
good, so a rise in returns reads red and a rise in revenue green, and a screen reader hears which.
Without `good`, a change stays neutral.

## Usage

```bash
npm install @aparte/plugin-cards @aparte/core
```

```ts
import { setupStatsCard } from '@aparte/plugin-cards/stats';

setupStatsCard({
  tool: 'get_sales_summary',
  map: (result) => ({
    title: 'Sales this week',
    items: [
      { label: 'Revenue', value: result.revenue, currency: 'EUR', change: result.revenueChange, good: 'up', trend: result.daily },
      { label: 'Returns', value: result.returns, change: result.returnsChange, good: 'down' },
    ],
  }),
});
```

A change up to 1 is a ratio (`0.12` reads +12 %). Formats, units and icons are in
[the guide](/guides/cards/#key-figures--stats).
