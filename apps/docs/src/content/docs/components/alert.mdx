`.aparte-alert` is a callout: an `__icon`, a `__body` holding a `__title` and a `__message`, and
an optional `__dismiss` button. Its intent (info, success, warning, danger, neutral, primary,
secondary) colours it. The chat's [error](/components/error/) card wears this recipe, and so do
this site's notes and warnings.

## Accessibility

- An alert that appears while someone is reading takes `role="status"` (or `role="alert"` when it
  must interrupt); one that is part of the page from the start needs neither.
- The intent is written in the title or the message, not only coloured.
- The dismiss button shows a cross: give it an `aria-label`.
