<Variant id="message-actions" />

Every message can carry a row of actions, and none is on by default: turn on the ones your chat
wants with `aparteGlobalConfig.setBubbleActions()`. Copy the library does alone, so
`setBubbleActions({ copy: true })` is all it takes. The others only ask: retry and edit need
something that re-sends and rewrites the conversation, feedback and details need a listener. So
they stay off until your app says it handles them, and a button never sits there answering to
nobody.

`AparteClient` handles retry and edit for you, so with the client running,
`setBubbleActions({ retry: true, edit: true })` is all it takes.

## Variants

### In an order of your own

<Variant id="message-actions-order" />

A list for a role replaces the flags for that role: those buttons, in that order. Naming a
button in the list is the opt-in.

### Token usage behind a details button

<Variant id="message-actions-info" />

The details button appears only on a message that carries `usage`, and it only emits
`aparte-message-info`: the popover with the numbers is yours to draw.

## Usage

```ts
import { aparteGlobalConfig } from '@aparte/core';
import type { AparteFeedbackEventDetail } from '@aparte/core';

aparteGlobalConfig.setBubbleActions({ copy: true, retry: true, edit: true, feedback: true });

document.addEventListener('aparte-feedback', (e) => {
  const { messageId, value } = (e as CustomEvent<AparteFeedbackEventDetail>).detail;
  void fetch('/api/feedback', { method: 'POST', body: JSON.stringify({ messageId, value }) });
});
```

| Action | Default | Needs |
| --- | --- | --- |
| `copy` | off | nothing |
| `retry` | off | a host that re-sends (`AparteClient`) |
| `edit` | off | a host that keeps the new text (`AparteClient`) |
| `feedback` | off | a listener for `aparte-feedback` |
| `info` | off | a listener for `aparte-message-info`, and `usage` on the message |

## Accessibility

- Each action is a button named from the locale (`copy`, `retry`, `edit`, `feedbackPositive`,
  `messageInfo`…), so a row of icons still reads as words.
- The row is hidden while a reply streams, so nobody copies half an answer.
