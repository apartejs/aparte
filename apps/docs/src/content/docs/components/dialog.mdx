`.aparte-dialog` styles the browser's own `<dialog>`, which already does what a modal needs:
opened with `showModal()`, it sits above everything, keeps the focus inside, closes on Escape,
gives the focus back and dims the page behind a backdrop. The recipe draws a `__header` with a
`__title` and a `__close` button, a `__body` and a `__footer` for the actions.

Core adds the wiring. A control with `data-aparte-dialog-open="settings"` opens the dialog whose
id is `settings`; a control inside with `data-aparte-dialog-close` closes it; a click on the
backdrop closes it too, unless the dialog carries `data-aparte-dialog-static`.

## Accessibility

- Name the dialog with `aria-labelledby` pointing at its title.
- The close button shows a cross: give it an `aria-label`.
- Keyboard, focus and Escape are the browser's, through `showModal()`.
