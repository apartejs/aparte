`.aparte-tag` is a chip: a label in a quiet outline, `--sm` for a smaller one. A
`.aparte-tag__remove` button inside it removes it, for a list of filters or of chosen items. The
[header](/components/header/) uses one for the model's name, and the question receipt is a tag
with a [mark](/components/mark/).
