<Variant id="composer" />

The composer is a set of parts you arrange yourself. `<aparte-composer>` holds the state — the
text, the pending files, whether a reply is streaming — and every part reads it from there, at
any depth. It draws nothing of its own: the two classes in the example, `.aparte-composer-shell`
and `.aparte-composer-row`, give it the usual look, and without them the parts still work
wherever your layout puts them.

Inside an [`<aparte-chat>`](/components/chat/), the message goes to the chat's client. On its
own, listen for `aparte-send` on the composer.

## Variants

### With files attached

<Variant id="composer-attachments" />

`<aparte-composer-add-attachment>` opens the file picker and makes the whole composer a drop
target; `<aparte-composer-attachments>` shows the files waiting to be sent. They reach you on
`aparte-send`, as `event.detail.files`: reading or uploading them is your app's job.

### With a toolbar

<Variant id="composer-toolbar" />

`<aparte-composer-toolbar>` is the row under the field for a model picker, a mode switch or your
own buttons. Children keep their DOM order; `margin-inline-start: auto` on one pushes it, and
everything after it, to the end of the row. An `<aparte-composer-action>` is an icon button that
only emits `aparte-action-click`: what it does is up to you.

### While a reply streams

<Variant id="composer-streaming" />

The send button becomes a stop button, and a click cancels the turn. The client sets
`streaming` for you; this demo sets it by hand. If stop should live somewhere else as well,
add `<aparte-composer-cancel>`.

## Customize

The field and the button read the input and button tokens, so a theme reaches them with no
selector: `--aparte-input-bg`, `--aparte-input-border`, `--aparte-radius-input` and
`--aparte-input-focus-border` for the field, `--aparte-primary` for the button, and
`--aparte-composer-control-size` for the height they share. Every variable is listed under
API below.

Enter sends and Shift+Enter starts a new line; `submit-on-enter="false"` swaps the two. A
button of your own can send or stop through `composer.submit()`, which cancels instead while a
reply streams:

```js
composer.addEventListener('aparte-composer-change', (e) => {
  const { streaming, disabled, value, attachments } = e.detail.state;
  myButton.textContent = streaming ? 'Stop' : 'Send';
  myButton.disabled = disabled || (!streaming && !value.trim() && attachments.length === 0);
});
myButton.addEventListener('click', () => composer.submit());
```

## Accessibility

- The field is a multi-line `textbox`, named by its placeholder.
- The send button's name follows what it does: Send, Stop while a reply streams, Submit when a
  question panel is open. All three are locale keys (`sendButton`, `stopButton`, `submitButton`).
- Enter never sends in the middle of an IME composition, so confirming a Chinese or Japanese
  candidate does not send the message.
