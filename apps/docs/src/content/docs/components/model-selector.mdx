`<aparte-model-selector>` lists the providers your config knows, one group per provider, with
the models each one fetches. A provider with no list to fetch shows the models it was given (the
Vercel AI SDK bridge's `models` option), and one given none is left out. With a single provider it
is a flat list. With `persist`, the choice is what the
next message is sent to: the pick is written into the config. Without it, the element only sends
`aparte-model-change`, for code of yours to act on.

It is built on core's [select](/components/select/), and it reads the config of the chat it sits in,
so two chats on one page each list their own models.

## Usage

```bash
npm install @aparte/plugin-model-selector @aparte/core
```

```ts
import '@aparte/plugin-model-selector'; // registers the element
```

Its place is the composer's toolbar. `margin-inline-start: auto` pushes it to the end of the
row; the four framework wrappers take it through their `toolbar` slot (see
[the composer toolbar](/guides/customization/composer-toolbar/)).

```html
<aparte-composer-toolbar>
  <aparte-model-selector auto-select persist searchable style="margin-inline-start: auto"></aparte-model-selector>
</aparte-composer-toolbar>
```

The plugin types its own element, one subpath per framework, so the tag is checked as soon as
you import that subpath once:

Outside Angular, a presence attribute is `''` to set and `null` to remove, never `false`
([the rule](/frameworks/elements/#presence-attributes)). The
framework packages are optional peer dependencies: you carry only the one you use.

## Customize

The list loads asynchronously, so for a moment the chat can be mounted with no model chosen.
To keep the composer from sending until one is:

```ts
import { aparteGlobalConfig } from '@aparte/core';

aparteGlobalConfig.setRequireModelSelection(true);
```

The composer greys out and comes back once a pick reaches the config: `auto-select` or the
reader's choice, on a selector with `persist`.

## Accessibility

- The button is named by its placeholder and the current model, and opens a list box;
  `searchable` adds a filter field.
- Providers are option groups, so a screen reader names the provider of each model.
