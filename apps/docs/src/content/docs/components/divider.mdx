`.aparte-divider` separates two parts of a panel: horizontal by default, vertical between items
in a row, and labelled when a word helps ("or"). The line is a border, not a background, so it
stays visible in forced-colours mode.

## Accessibility

- A divider that separates sections can be an `<hr>`, or carry `role="separator"`; one that is
  only visual takes `aria-hidden="true"`.
