`.aparte-spinner` is a ring that turns, in three sizes (`--sm`, the default, `--lg`), for a wait
of unknown length: a button that is sending, a list that is loading.

## Variants

### With progress

<Variant id="progress-spinner" />

`<aparte-progress-spinner>` turns while it has no `value`, and fills its ring to the `value`
(0 to 100) once it has one: a model being downloaded, a file being read.

## Accessibility

- `<aparte-progress-spinner>` is a `progressbar`, with its value once it has one. It has no name
  of its own: give it an `aria-label` unless the text beside it says what is loading.
- The `.aparte-spinner` class is drawing only: put `role="status"` and a visually hidden label on
  what it sits in, or let the surrounding text say it.
- Both stop turning under `prefers-reduced-motion`.
