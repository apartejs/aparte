`<aparte-icon name="copy">` draws one of the glyphs the chat itself uses, from markup, with no
script of your own. A glyph carries no size: it takes `--aparte-icon-size` from its container, so
the same drawing serves a small remove button and a large toolbar. `--sm`, `--lg` and `--xl`
change it on one icon.

An icon provider (`aparteGlobalConfig.setIconProvider()`) replaces the set, for the chat and for
every `<aparte-icon>` at once. The full reference, with the extended set behind
`@aparte/core/icons`, is on the [icons page](/reference/icons/).

## Accessibility

- The drawing is hidden from screen readers: an icon beside a label is decoration. When the icon
  is the only content of a button, name the button with `aria-label`.
