`.aparte-kbd` draws a key: a small raised label in the code typeface, for a shortcut written in a
hint, a menu or a placeholder. The search field of this site shows one.

## Accessibility

- Put the class on a `<kbd>` element, which says to a screen reader that this is keyboard input.
  Write the key's name as text ("Ctrl", "Esc"), not as a symbol alone.
