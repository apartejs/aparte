Retrying a reply does not throw the old version away: it forks the conversation. The reply gets a
sibling, and a `‹1/2›` picker appears on it as soon as there is more than one version. Editing a
question rewrites it in place and drops the replies under it. Moving between them shows the whole conversation that followed each
version, because the [transcript](/components/conversation/) keeps the tree and renders one path
through it.

With `AparteClient` running and retry turned on (see
[Message actions](/components/message-actions/)), you write nothing more: the client forks, the
viewport keeps the tree, the picker appears.

## Usage

The picker is drawn from the tree, so markup alone never places it. On a message you draw
yourself, `setSiblings(count, index)` says how many versions exist and which one is shown, and
`aparte-branch-navigate` tells you when the reader moves:

<TabItem label="Vanilla">

```js
bubble.setSiblings(2, 0);
bubble.addEventListener('aparte-branch-navigate', (e) => showVersion(e.detail));
```

</TabItem>
<TabItem label="React">

```tsx
import { useEffect, useRef } from 'react';
import { useAparteEvent } from '@aparte/react';
import type { AparteChatBubble } from '@aparte/core';

declare function showVersion(navigation: unknown): void;   // yours

export function MyBubble() {
  const bubble = useRef<AparteChatBubble>(null);

  useEffect(() => {
    bubble.current?.setSiblings(2, 0);
  }, []);
  useAparteEvent(bubble, 'aparte-branch-navigate', (e) => showVersion(e.detail));

  return <aparte-chat-bubble ref={bubble} />;
}
```

```ts
import { AfterViewInit, Component, ElementRef, viewChild } from '@angular/core';
import { AparteChatBubbleDirective } from '@aparte/angular';
import type { AparteChatBubble } from '@aparte/core';

declare function showVersion(navigation: unknown): void;   // yours

@Component({
  selector: 'app-my-bubble',

    this.bubble().nativeElement.setSiblings(2, 0);
  }

  show(navigation: unknown) {
    showVersion(navigation);
  }
}
```

On the transcript, `addBranch()`, `addSiblingOf()` and `navigateBranch()` build and walk the
tree; `exportTree()` and `importTree()` save and restore it with the conversation. The
[conversations and branching guide](/guides/conversations-branching/) shows the whole flow.

## Customize

`setSiblingNavRenderer()` draws the counter between the arrows your way, for a product that writes
"Version 2 of 3" or draws dots; the arrows stay.

## Accessibility

- The previous and next buttons are named from the locale (`previousResponse`, `nextResponse`).
- The position (2 of 3) is announced through a polite live region when the reader moves.
