`.aparte-thumbnail` is a fixed square that clips what you put in it: an image, or a label with
the file's type when there is no picture. It is the tile [attachments](/components/attachments/)
are drawn with, in the composer and in a message.

It looks like an [avatar](/components/avatar/) and is a different thing: an avatar stands for a
person and falls back to initials; a thumbnail stands for a file, falls back to its type, and
leaves room in a corner for a remove button or a badge.

## Accessibility

- An image needs an `alt`, or the file's name next to it; a remove button needs a name that says
  which file it removes.
