`<aparte-select>` is the dropdown the [model selector](/components/model-selector/) and the
[approval mode](/components/approval-mode/) switch are built on. Its options are
`<aparte-option>` children, optionally grouped in `<aparte-optgroup>`. The value is an attribute;
a change fires `aparte-select-change` with the new value, its label and the previous value.

## Variants

### Groups and a search field

<Variant id="select-grouped" />

`searchable` adds a field that filters the options as you type. A group has a `label`; it can be
`collapsible`, and `loading` adds a spinner row while its options arrive.

## Accessibility

- The trigger is a combobox (a button when the list is searchable) that opens a list box; the
  arrow keys move through the options, Enter picks one, Escape closes.
- A group is a labelled group, so a screen reader names it with each option.
- Give the select an `aria-label`, or a placeholder that says what it chooses.
