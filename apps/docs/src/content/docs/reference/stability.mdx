import frozen from '../../../data/frozen-surface.json';

export const elements = Object.entries(frozen.elements).map(([tag, e]) => ({ tag, ...e }));
export const elementPackages = [...new Set(elements.map((e) => e.package))];
export const attributeCount = elements.reduce((n, e) => n + e.attributes.length, 0);
export const exportRows = Object.entries(frozen.exports);
export const exportCount = exportRows.reduce((n, [, names]) => n + names.length, 0);
export const eventCount = frozen.events.typed.length + frozen.events.names.length;
export const codeList = (names) => names.map((name, i) => (<span key={name}>{i > 0 ? ', ' : ''}<code>{name}</code></span>));
export const count = (n, word) => `${n} ${word}${n === 1 ? '' : 's'}`;

## The promise

| Frozen | Not frozen |
| --- | --- |
| element tags and the attributes they document | the methods of an element or of an exported class |
| event names | the fields of an interface, an event's `detail` included |
| the functions, classes and constants a package's main entry exports | type names, and what a subpath entry exports (`/icons`, `/core`, `/react`…) |
| the keys of `AparteLocale` | the keys a plugin adds to the locale |
| `--aparte-*` token names | a token's default value; class names, the kit's included; default colours, spacing and English labels; the docs, the example apps, `@aparte/docs-mcp` |

The promise holds since **{frozen.frozenSince.version}**, and a name added since is frozen from
the release that added it. A frozen name leaves in two steps:

1. **A notice release**: the old name still works, and the [changelog](/changelog/) and its JSDoc
   mark it deprecated — your editor strikes it through — with the release it disappears in and its
   replacement.
2. **A removal release**, at least one minor later.

One name has left without a notice release: 0.27.0 removed the package `@aparte/locale-fr` and its
`fr` in one step. The same `fr` is now `@aparte/locales/fr`; the [changelog](/changelog/) says so.

Adding is always allowed: a new optional attribute, a new optional field on an event's `detail`, a
new export. What is not frozen can change in a minor, and the changelog says so: read it before
you implement an exported type yourself, or build on a class name.

documented attributes between them; a property that mirrors an attribute freezes with it.

## The tokens

**{frozen.tokens.length}** `--aparte-*` custom properties, every one on the
[CSS variables reference](/reference/css-variables/). A token's default value can change in any
minor; its name stays.

<details>
  <summary>The tokens</summary>
  <p>{codeList(frozen.tokens)}</p>
</details>

Every class core emits carries the `aparte-` prefix — except `language-*` on a code block, the name
highlighters read — so none collides with a class of yours.
