These packages are built on aparté but are not part of the library. Each lives in its own
repository, with its own versions, issues and changelog, and depends on **exact** versions of
aparté's packages: it moves to a newer aparté only in a release of its own, so what you install
keeps running as you tested it while aparté goes on releasing.

| Package | What it is |
| --- | --- |
| [`@aparte/n8n-chat`](/other-plugins/n8n-chat/) | n8n's chat widget, drawn by aparté: `createChat()` takes `@n8n/chat`'s options. From npm or a CDN. |

Their README is their reference; this section says what each is for and where to find it. An issue
about one goes to its own repository.
