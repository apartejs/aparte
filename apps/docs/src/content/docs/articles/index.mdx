Dated pieces on what changes around agents and the chats in front of them, and what it means for a
page that hosts one. Each article names its sources, and the code it shows is tested, in this
repository or in the package's own.

- **[n8n's chat widget: what people run into, and a replacement that takes the same call](/articles/n8n-chat-widget/)**,
  October 27, 2026. The problems n8n users report most with `@n8n/chat`, with their sources, what
  n8n 3.0 changes for a chat widget, and `@aparte/n8n-chat`, a `createChat` that takes the same
  options, tested against a live n8n.
- **[Agent Builder shuts down on November 30: stop tying your chat UI to a vendor](/articles/agent-builder-shutdown/)**,
  October 26, 2026. What stops when OpenAI closes Agent Builder, the migration path, and how an
  open protocol between the agent and the chat makes the next shutdown cheaper. With a demo that
  runs without a key.
