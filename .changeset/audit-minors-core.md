Small fixes from the audit's minor findings. `createAparteChatHandler` answers a failed vendor fetch with a fixed `502 Vendor request failed.` (the exception message could name a URL carrying the key) and 400 on an inherited `providerId` such as `__proto__` (it used to fall through to a 500). `modelSelectorPlaceholder` and `approvalModeLabel` are declared fields of `AparteLocale` (no value or behaviour changes). Attachment tooltips and alt text no longer double-escape a filename (`A & B.png` reads as itself). `cssEscape` also escapes a newline. A second send arriving while the first is still creating the conversation waits for it, so the two messages keep their order and the auto-title comes from the first. `updateMessage({ segments })` on a bubble copies the array in, as `setSegments` does. The `headers` JSDoc says the session cookie only rides a same-origin endpoint; `setBubbleActions`'s example no longer claims `{ copy: false }` hides everything; `AparteClient` loses an abort-controller set nothing ever added to.
